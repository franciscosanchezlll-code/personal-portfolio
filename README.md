# Personal Portfolio Website

A responsive, modern personal portfolio website built with **HTML5**, **CSS3**, and **JavaScript**, showcasing my personal profile, educational background, technical skills, projects, achievements, and contact information.

## Features
- **Responsive Design:** Adapts cleanly to desktop, tablet, and mobile viewports.
- **Dark / Light Mode Toggle:** Persistent theme switching using `localStorage`.
- **Interactive Project Filtering:** Filter projects by category (`All`, `Web Dev`, `Mobile / Game`).
- **Scroll Reveal & Active Navigation:** Smooth scrolling with automatic section highlighting.

## Sections Included
1. **Home** – Name, dynamic typing introduction, tagline, and quick navigation.
2. **About Me** – Personal bio and educational background timeline.
3. **Skills** – Frontend, programming languages, and development tools.
4. **Projects** – Featured completed software, mobile, and web projects.
5. **Achievements** – Certifications, awards, and seminars attended.
6. **Contact Me** – Direct contact details and interactive message form.

## Deployment
Hosted on **GitHub** and deployed continuously via **Vercel**.
